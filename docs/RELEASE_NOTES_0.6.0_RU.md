# SvoRay 0.6.0

WireGuard и Cloudflare WARP на простом экране, в том числе WARP-конфиги, сделанные для
AmneziaWG. Всё остальное — как в [0.5.2](https://github.com/ValenokMC/SvoRay/releases/tag/v0.5.2).

## WireGuard и WARP

Под кнопкой «Импортировать» появилась кнопка **«Выбрать файл .conf»**. Конфиг можно и просто
вставить в поле целиком: SvoRay узнает его и импортирует сразу. Раньше однострочное поле
оставляло от вставленного конфига только первую строку. Профиль WARP называется
«Cloudflare WARP».

## Конфиги WARP для AmneziaWG

Обычный WireGuard в России режется по сигнатуре рукопожатия, поэтому WARP-конфиги обычно делают
для AmneziaWG: в них есть строки `Jc`, `Jmin`, `Jmax` и `I1`–`I5`. Сервер WARP при этом работает
на обычном WireGuard, а обход DPI целиком на стороне клиента: перед каждым рукопожатием клиент
отправляет пакеты-приманки, которые сервер просто отбрасывает.

SvoRay теперь делает то же самое. Ядро (Xray или sing-box) подключается к небольшому
ретранслятору внутри SvoRay, а тот пересылает трафик на сервер WARP. Перед каждым рукопожатием он
отправляет сначала пакеты `I1`–`I5`, затем `Jc` пакетов случайных данных размером от `Jmin` до
`Jmax` байт — в том же порядке, что и AmneziaWG. Остальной трафик идёт без изменений. Новое ядро
не понадобилось, поэтому TUN, список доменов и игровой режим работают как с любым другим
сервером.

Поддерживаемые теги приманок: `<b 0x…>`, `<r N>`, `<rc N>`, `<rd N>` и `<t>`.

## Что не поддерживается

- **Конфиги для собственных серверов AmneziaWG**, где заданы нестандартные `H1`–`H4` или
  ненулевые `S1`–`S4`. Им нужен сервер AmneziaWG, поэтому SvoRay не импортирует такой конфиг, а
  объясняет причину. Раньше такой профиль импортировался бы, но никогда бы не подключился.
- При экспорте профиля ссылкой `wireguard://` параметры AmneziaWG в неё не попадают: у этого
  формата нет для них полей.

## Как обновиться

- **С 0.5.x:** SvoRay сам предложит обновление при ежедневной проверке; сразу — по кнопке внизу
  слева.
- **С 0.4.x и раньше:** скачайте установщик по ссылке
  <https://github.com/ValenokMC/SvoRay/releases/latest/download/SvoRay-setup.exe> и запустите поверх
  установленной версии.

## Проверено

- 259/259 модульных тестов, в том числе новые: разбор WARP-конфига для AmneziaWG и отказ для
  конфигов, которым нужен сервер AmneziaWG; сборка приманок по тегам; ретранслятор на настоящих
  UDP-сокетах (порядок приманок перед рукопожатием, пересылка в обе стороны без изменений); адрес
  ретранслятора в конфигах Xray и sing-box.
- Владелец проверил живой WARP-конфиг: импорт, подключение, трафик идёт.
