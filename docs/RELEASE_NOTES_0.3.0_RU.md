# SvoRay 0.3.0

Версия добавляет выбор способа подключения и собственную маршрутизацию по доменам, а простой экран переведён на узкое окно телефонного формата.

## Выбор режима подключения

На главном экране появился переключатель **Прокси / TUN**. Выбор сохраняется и восстанавливается при запуске.

- **TUN** — как в 0.2.0: виртуальный адаптер, через VPN идёт весь трафик системы.
- **Прокси** — системный прокси Windows. Через VPN идут браузеры и программы, которые его учитывают; остальные работают напрямую. Привязка к сетевому адаптеру и исключение IP сервера из тоннеля в этом режиме не применяются — они нужны только TUN.

Состояние «включён / выключен» теперь считается по тому переключателю, который используется текущим режимом, поэтому кнопка питания, иконка в трее и автоматическое восстановление подключения при запуске одинаково работают в обоих режимах.

Смена режима на активном подключении сначала выключает старый режим его же переключателем и только затем поднимает новый: иначе за спиной остался бы либо системный прокси, либо тоннель.

Особенность режима «Прокси»: «выключено» означает, что системный прокси снят, но процесс ядра продолжает работать — так устроен v2rayN. Трафик через него при этом не идёт.

## Маршрутизация по доменам

Кнопка **Маршрутизация** открывает список доменов и выбор того, как он применяется:

- **Всё через VPN, кроме списка** — домены из списка идут напрямую. Для банка, госуслуг, локальных сервисов.
- **Через VPN только список** — остальной трафик идёт напрямую.

Домен вводится как `example.com`; поддомены попадают в правило автоматически. Ввод нормализуется — `https://www.example.com/path`, `example.com:443` и `*.example.com` дают одно и то же правило, дубликаты отбрасываются.

Под капотом SvoRay генерирует собственный профиль маршрутизации и делает его активным. Профиль пересобирается заново при каждом подключении и при каждой правке списка, поэтому редактировать его в расширенном режиме бессмысленно — изменения будут перезаписаны.

Важное следствие такой реализации: DNS настраивается сам. Генератор конфигурации ядра видит правило с `direct` и отправляет эти домены на прямой DNS-сервер. Иначе домен уходил бы мимо VPN, но резолвился через него и возвращал адрес, выбранный «не для той страны».

### Ввод списка

Домены можно вставлять пачкой: поле ввода принимает список, разделённый переносами строк, запятыми, точками с запятой или пробелами. Enter добавляет введённое, Shift+Enter переносит строку.

Кнопка **Набор для РФ** заполняет список 88 доменами, которые обычно не работают с зарубежного адреса: госуслуги и налоговая, крупные банки и платёжные сервисы, Яндекс, VK и Mail.ru, маркетплейсы, операторы связи, российские видеосервисы. Вместе с ними добавляются домены их статики и картинок (`gu-st.ru`, `yastatic.net`, `userapi.com`, `ozone.ru`, `wbbasket.ru`, `avito.st`, `imgsmail.ru`): сайт, страницы которого идут напрямую, а картинки — через тоннель, самый частый способ получить наполовину рабочую страницу. Набор дополняет уже введённое, ничего не затирая, и переключает режим на «всё через VPN, кроме списка», если был выбран обратный.

Встроенный набор — снимок, сверенный с поддерживаемым сообществом списком [itdoginfo/allow-domains](https://github.com/itdoginfo/allow-domains) (`Russia/outside` — «российские ресурсы, доступные только для российских подсетей»). При нажатии кнопка сначала добавляет встроенный набор, а затем пытается скачать актуальную версию этого списка и дополнить им — так кнопка работает и без интернета, а с интернетом приносит свежие записи без выпуска новой версии. Загрузка идёт сначала через запущенный тоннель, потом напрямую: сам GitHub из России часто недоступен. Если скачать не удалось, об этом сообщается, а встроенный набор всё равно добавлен.

Поддерживаемый список содержит только то, что строго требует российского адреса (госуслуги, РЖД, ЖКХ, часть магазинов). Банки, VK, Яндекс, маркетплейсы и операторов в нём нет — они добавлены в встроенный набор отдельно, вместе с доменами их статики.

Набор — отправная точка, а не гарантия: домены со временем меняются, а запись, которая больше ни во что не резолвится, просто никогда не сработает.

QUIC (UDP 443) блокируется только на том трафике, который реально уходит на сервер: в режиме исключений — на всём, кроме списка (как в штатном профиле Global v2rayN), в обратном режиме — только на доменах списка.

## Окно и вёрстка простого экрана

- Простой экран стал узким окном телефонного формата: 420×780 по умолчанию, минимум 360×560, максимальная ширина 560.
- Расширенный режим сохранил десктопные размеры. Каждый режим запоминает свой размер на время сессии, поэтому переключение туда и обратно не отменяет ручную подгонку окна.
- Карточка теперь прокручивается, а не обрезается. В 0.2.0 при стандартном размере окна нижняя часть карточки могла уйти за край без возможности до неё добраться.
- Заголовок компактнее: кнопка расширенного режима стала иконкой, подписи и отступы уменьшены под ширину телефона.
- Кнопка «Обновить» больше не подменяет свою подпись длинным вариантом «Обновить подписку» после завершения обновления.

## Проверка соединения

Кнопка **Проверить** раньше работала только при выключенном VPN и измеряла выбранный профиль, поднимая для этого второе ядро. Теперь при включённом VPN она проверяет уже работающее соединение: запрос идёт через локальный порт запущенного ядра, и в строке статуса появляется «VPN работает, выход в интернет: NL. Задержка 118 мс».

Это отвечает ровно на тот вопрос, ради которого обычно открывают сайт с проверкой IP, и надёжнее его: проверяется сам тоннель, а не то, что настроено в браузере. Особенно заметно в режиме «Прокси», где браузер может не использовать системный прокси, и сайт покажет настоящий адрес при полностью рабочем VPN.

Показывается страна выхода, а не IP-адрес: адрес выхода — это адрес вашего сервера, который простой экран намеренно не выводит. Полные данные доступны в расширенном режиме. Страна определяется запросом к `api.ip.sb` через тот же прокси; запрос уходит только по нажатию кнопки.

## Совместимость

Обновление устанавливается поверх 0.2.0, настройки, подписки и профили сохраняются. Новые параметры (режим подключения, режим маршрутизации, список доменов) добавляются в конфигурацию со значениями по умолчанию: TUN, «всё через VPN», пустой список — то есть поведение по умолчанию совпадает с 0.2.0.

## Проверено

- Сборка без ошибок и предупреждений компилятора.
- 91/91 модульных тестов, из них 29 новых: нормализация доменов, порядок и содержимое сгенерированных правил в обоих режимах, а также прогон этих правил через настоящий генератор конфигурации sing-box — проверяется, что домен попадает и в правила маршрутизации, и в правила DNS, и что в режиме «только список» финальный DNS становится прямым.

Проверено вживую: простой экран в узком окне, маршрутизация — добавленные сайты действительно идут мимо VPN.

Не проверено вживую: переключение режимов на уже работающем подключении и набор для РФ целиком — домены в нём подобраны по назначению сайтов, а не проверены запросом к каждому.
