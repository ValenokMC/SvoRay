# SvoRay 0.6.3

В списке серверов вместо букв «DE», «FI», «RU» теперь флаги. Всё остальное — как в
[0.6.2](https://github.com/ValenokMC/SvoRay/releases/tag/v0.6.2).

## Флаги стран

Провайдеры ставят перед названием сервера эмодзи-флаг, а Windows не умеет его рисовать и показывает
две буквы. Теперь флаг вырезается из названия и показывается картинкой:

- в раскрытом списке — перед названием сервера;
- в закрытом поле выбора — перед выбранным сервером;
- в заголовке подписки — вместо значка, если флаг есть в её названии.

Если в названии нет эмодзи-флага, строка выглядит как раньше. Меню в трее осталось текстовым.
Флаги встроены в программу, интернет для них не нужен; набор — [flag-icons](https://github.com/lipis/flag-icons)
(лицензия MIT).

## Как обновиться

- **С 0.5.x и 0.6.x:** SvoRay сам предложит обновление при ежедневной проверке; сразу — по кнопке
  внизу слева.
- **С 0.4.x и раньше:** скачайте установщик по ссылке
  <https://github.com/ValenokMC/SvoRay/releases/latest/download/SvoRay-setup.exe> и запустите поверх
  установленной версии.

## Проверено

- Модульные тесты, в том числе новый на разбор флага в названии.
- Сборка без предупреждений.
