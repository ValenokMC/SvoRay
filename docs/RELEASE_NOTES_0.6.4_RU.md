# SvoRay 0.6.4

Kill Switch, запуск вместе с Windows и быстрое переключение серверов. Всё остальное — как в
[0.6.3](https://github.com/ValenokMC/SvoRay/releases/tag/v0.6.3).

## Kill Switch

Новый переключатель на простом экране. Пока VPN включён, интернет работает только через него:
ничего не уходит напрямую ни во время подключения, ни после обрыва, ни при переключении между
«Прокси» и TUN.

- Открытыми остаются туннель, сами ядра и SvoRay, локальная сеть (роутер, принтер, NAS), DHCP и
  адрес VPN-сервера: некоторые провайдеры отдают через него заблокированные сервисы.
- DNS-запросы к роутеру блокируются: роутер передал бы их провайдеру, и тот увидел бы все сайты.
- Пока Kill Switch включён, ядро само определяет адреса своим DNS, а не через Windows. Поэтому
  туннель не теряет сервер, когда у Windows истекает кэш.
- Фильтры живут в динамической сессии Windows Filtering Platform: если SvoRay закрыть, она упадёт
  или обновится, Windows снимет их сама, и интернет сразу вернётся.
- В режиме «Прокси» при включённом Kill Switch работают только программы, которые используют
  системный прокси. Telegram, Claude Desktop и многие игры его не используют — для них лучше TUN.

По умолчанию Kill Switch выключен.

## Запуск вместе с Windows

Второй новый переключатель. SvoRay регистрирует задачу в Планировщике с наивысшими правами, поэтому
при входе в систему запрос UAC не появляется. Программа стартует в трее, ждёт сеть и подключается.
При удалении SvoRay задача удаляется.

## Быстрое переключение серверов

- Сервер из той же подписки меняется без перезапуска ядра: новый сервер подставляется на ходу,
  туннель и локальный прокси не пересоздаются. Само переключение занимает доли секунды; на
  проверке в режиме «Прокси» первый трафик через новый сервер шёл через 2–4 секунды — это время на
  соединение с новым сервером.
- Другая подписка, режим или маршрутизация по-прежнему перезапускают ядро, но быстрее: без
  фиксированных пауз и без удаления адаптера TUN при каждом переключении.

## Исправления

- Строка «VPN работает · страна · мс» после проверки и другие короткие сообщения теперь всплывают
  поверх нижней строки. Раньше они выталкивали содержимое за край окна: появлялась прокрутка, и
  экран дёргался.
- Если ядро остановилось само, экран больше не показывает «VPN включён», а сообщает об ошибке.
- Правила DNS в Xray: прямые DNS-запросы ядра теперь действительно идут напрямую, а не через прокси.

## Как обновиться

- **С 0.5.x и 0.6.x:** SvoRay сам предложит обновление при ежедневной проверке; сразу — по кнопке
  внизу слева.
- **С 0.4.x и раньше:** скачайте установщик по ссылке
  <https://github.com/ValenokMC/SvoRay/releases/latest/download/SvoRay-setup.exe> и запустите поверх
  установленной версии.

## Проверено
