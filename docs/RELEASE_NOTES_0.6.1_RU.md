# SvoRay 0.6.1

Удобнее добавлять подключения и удалять подписки. Всё остальное — как в
[0.6.0](https://github.com/ValenokMC/SvoRay/releases/tag/v0.6.0).

## Ссылка или файл

В форме добавления появились две вкладки:

- **Ссылка** — поле и кнопка «Импортировать», как раньше. Конфиг WireGuard, вставленный сюда
  текстом, по-прежнему импортируется сразу.
- **Файл .conf** — одна большая кнопка, которая открывает выбор файла: WireGuard, WARP или
  AmneziaWG.

Перетащить файл в окно нельзя: SvoRay работает с правами администратора, а Windows не пропускает
в такое окно файлы, перетащенные из обычного Проводника.

## Подписки в списке серверов

Раскрытый список серверов теперь сгруппирован:

- над серверами каждой подписки — её название и число серверов, справа корзина: она удаляет
  подписку вместе с серверами (после подтверждения);
- серверы, добавленные по одной ссылке или из файла, собраны в группу «Отдельные серверы», у
  каждого свой крестик удаления;
- последняя строка — «Добавить подписку или файл…».

Меню «…» над списком больше не нужно и убрано. Заголовки групп нельзя выбрать как сервер, а
стрелки клавиатуры их пропускают.

## Как обновиться

- **С 0.5.x или 0.6.0:** SvoRay сам предложит обновление при ежедневной проверке; сразу — по
  кнопке внизу слева.
- **С 0.4.x и раньше:** скачайте установщик по ссылке
  <https://github.com/ValenokMC/SvoRay/releases/latest/download/SvoRay-setup.exe> и запустите поверх
  установленной версии.
