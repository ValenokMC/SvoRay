# SvoRay 0.5.2

Защита от подмены путей и постоянная ссылка на установщик. Всё остальное — как в
[0.5.0](https://github.com/ValenokMC/SvoRay/releases/tag/v0.5.0).

## Безопасность

SvoRay работает с правами администратора и при поиске игр читает записи лаунчеров и реестр. Часть
этих записей лежит в папках, куда может писать любой пользователь компьютера (`ProgramData`).
Подложенный туда сетевой путь вида `\\сервер\share` заставил бы SvoRay открыть сетевой ресурс, и
Windows передала бы тому серверу данные для входа в учётную запись.

Теперь поиск игр, определение окончательного пути папки и файлы баз для правил с сервера
принимают только полные пути на локальном диске. Сетевые ресурсы, пути устройств, относительные
пути, подключённые сетевые диски и локальные ссылки, которые ведут на сетевой ресурс,
отбрасываются. Уязвимость нашёл анализатор CodeQL.

## Постоянная ссылка на установщик

В каждом релизе теперь есть копия установщика без номера версии в имени — `SvoRay-setup.exe`.
Поэтому ссылка

<https://github.com/ValenokMC/SvoRay/releases/latest/download/SvoRay-setup.exe>

всегда скачивает последнюю версию: её можно один раз отправить друзьям или закрепить, и она не
устареет. Встроенное обновление по-прежнему берёт файл с номером версии.

## Как обновиться

- **С 0.5.0 или 0.5.1:** SvoRay сам предложит обновление при ежедневной проверке; сразу — по
  кнопке внизу слева.
- **С 0.4.x и раньше:** скачайте установщик по ссылке выше и запустите поверх установленной версии.

## Проверено

- 228/228 модульных тестов, в том числе новые на сетевые ресурсы, пути устройств и относительные
  пути; Release-сборка без предупреждений; CodeQL без новых замечаний.
- Поиск игр на ПК владельца по-прежнему находит обе папки Steam.
