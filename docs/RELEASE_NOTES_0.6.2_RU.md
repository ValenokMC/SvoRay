# SvoRay 0.6.2

Игровой режим теперь только для TUN. Всё остальное — как в
[0.6.1](https://github.com/ValenokMC/SvoRay/releases/tag/v0.6.1).

## Игровой режим

В режиме прокси игры и так подключаются напрямую: системный прокси они не используют. Переключатель
«Игровой режим» там ничего не менял, поэтому теперь:

- в режиме прокси переключатель скрыт, правило «игры без VPN» не добавляется и папки с играми не
  ищутся;
- под «VPN включён» в режиме прокси больше не пишется «· игры напрямую»;
- в режиме TUN всё как раньше. Если игровой режим был включён, после возврата из прокси в TUN он
  снова включён.

## Как обновиться

- **С 0.5.x и 0.6.x:** SvoRay сам предложит обновление при ежедневной проверке; сразу — по кнопке
  внизу слева.
- **С 0.4.x и раньше:** скачайте установщик по ссылке
  <https://github.com/ValenokMC/SvoRay/releases/latest/download/SvoRay-setup.exe> и запустите поверх
  установленной версии.

## Проверено

- 264/264 модульных теста, в том числе новый: в режиме прокси правило для игр не появляется даже при
  включённом игровом режиме.
- Сборка без предупреждений.
