# SvoRay 0.2.0

## Главный экран

- Один динамический блок вместо отдельной постоянной карточки импорта. При отсутствии профилей показывается форма «Добавить подключение»; после успешного импорта она заменяется селектором профиля, и первый пригодный профиль выбирается автоматически.
- Кнопка «Добавить или заменить» возвращает форму импорта, когда профили уже есть.
- Повторный вывод имени выбранного профиля под селектором убран — имя показывается только в самом селекторе.
- Убраны карточка «Защита включается автоматически» и обещания защиты. Тексты нейтральные: `SvoRay`, `Личный VPN`, `VPN выключен` / `Подключение…` / `VPN включён` / `Ошибка подключения`.
- Ошибка импорта не закрывает форму и не показывает вставленную ссылку. Ссылка не попадает в логи: при сбое записывается только тип ошибки.
- Кнопка «Проверить» измеряет задержку выбранного профиля через сам прокси и показывает результат в миллисекундах с цветом по порогу. Доступна, когда VPN выключен.

## Состояния подключения

Введена явная модель `выключено / подключение / включено / ошибка`. Состояние `включено` выставляется только если процесс ядра действительно запустился, а не по факту запроса TUN. Одно и то же состояние используется главной карточкой и треем.

## Селектор профиля

- Выпадающий список точно совпадает по ширине с полем.
- Открывается вниз, а при нехватке места — вверх.
- Показывает около пяти строк, дальше прокрутка.
- Длинные имена обрезаются многоточием, полное имя доступно во всплывающей подсказке.
- Выбранный профиль отмечается галочкой; выдуманный индикатор доступности удалён.
- Показывается только имя профиля из подписки, без адреса и порта сервера. Селектор виден на любом скриншоте и при демонстрации экрана, а адрес — единственная часть профиля, указывающая на инфраструктуру пользователя.
- Исправлено: при количестве профилей больше лимита меню трея (по умолчанию 20) селектор оставался пустым. Теперь он всегда показывает все профили, лимитируется только подменю трея.

## Трей

- Четыре иконки состояний, различимые формой, а не только цветом: пустой контур, контур с точкой, залитый щит, щит с восклицательным знаком. Многоразмерный ICO (16/20/24/32/48/64) — Windows не масштабирует иконку в трее.
- Подсказка: `SvoRay — выключен` / `подключение…` / `включён` / `ошибка подключения`.
- Компактное меню: состояние, включить/выключить, профиль, обновить подписку, открыть окно, выход. Расширенные команды v2rayN остались в полном режиме.
- Левый клик открывает главное окно.

## Обновление подписки

Кнопка с обязательной подписью `Обновить подписку`. Во время работы блокируется и показывает `Обновляем…`, после успеха — `Обновлено`, при ошибке — понятное сообщение. Если подписок нет (импортирован одиночный профиль), кнопка скрыта.

## Хранение данных и установщик

- Настройки, подписки, профили и логи переехали в `%LOCALAPPDATA%\SvoRay`. Данные 0.1.x, лежавшие рядом с EXE, переносятся однократно при первом запуске.
- Появился один загружаемый установщик `SvoRay-0.2.0-setup.exe` (Inno Setup 6) со всеми компонентами: self-contained .NET runtime, Xray, sing-box, Wintun, geodata, AmazTool.
- Установка поверх предыдущей версии сохраняет настройки; перед заменой файлов установщик закрывает работающий клиент и ядро.
- Ярлык создаётся только в меню «Пуск».
- Деинсталлятор удаляет пользовательские данные только по явному выбору, по умолчанию — оставляет.

## Известные ограничения

- Сборка не подписана коммерческим сертификатом: Windows SmartScreen может показать «Неизвестный издатель».
- Установщик и деинсталлятор работают в повышенном контексте, поэтому `%LOCALAPPDATA%` относится к учётной записи, под которой выполнено повышение прав.
- Предпубликационный security-аудит проведён, вердикт «готово к публикации»: [docs/SECURITY_AUDIT.md](SECURITY_AUDIT.md). Не закрыты три проверки, не относящиеся к безопасности публикации: установка/обновление/удаление на отдельном профиле Windows, масштаб экрана 125 % и 150 %, живой тест подключения и TUN.
