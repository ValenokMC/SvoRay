# Security policy · Политика безопасности

## Supported versions

Security fixes are made for the latest published SvoRay release.

| Version | Supported |
| --- | --- |
| 0.4.x | Yes |
| 0.3.x and earlier | No — update first |

Исправления безопасности выпускаются для последней опубликованной версии. Перед сообщением о
проблеме обновитесь до актуального релиза и проверьте, воспроизводится ли она.

## Report a vulnerability privately

Do not open a public issue and do not include exploit details in Discussions or Telegram.

Use GitHub's private channel:
[Report a vulnerability](https://github.com/ValenokMC/SvoRay/security/advisories/new).

Include:

- the affected SvoRay version and Windows version;
- the smallest reproducible sequence of actions;
- the security impact;
- logs or screenshots only after removing subscription URLs, UUIDs, passwords, and server
  addresses.

If you cannot use GitHub, contact [@SupporBiBot](https://t.me/SupporBiBot) and ask for a private
security contact without sending technical details or credentials in the first message.

## Сообщить об уязвимости

Не создавайте публичный issue и не публикуйте детали эксплуатации. Используйте приватный раздел
[GitHub Security Advisories](https://github.com/ValenokMC/SvoRay/security/advisories/new). Укажите
версию SvoRay и Windows, минимальные шаги воспроизведения и возможные последствия. Перед отправкой
удалите из логов и скриншотов ссылки подписок, UUID, пароли и адреса серверов.

SvoRay is maintained by one person in spare time. Reports are reviewed as availability allows;
please do not disclose an unresolved vulnerability publicly while a fix is being prepared.
