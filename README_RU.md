Клиент предназначен для тех, кому нужны одна большая кнопка подключения, выбор сервера и простая вставка собственной ссылки. Полный интерфейс v2rayN остаётся в одном клике для всего, что не покрывает простой экран.

> ⭐ Если SvoRay упростил вам работу с v2rayN, поставьте репозиторию звезду. Так другие
> пользователи Windows смогут найти проект без рекламы и платного продвижения.

Что изменилось по версиям: [CHANGELOG.md](CHANGELOG.md). Подробные заметки к 0.4.0: [docs/RELEASE_NOTES_0.4.0_RU.md](docs/RELEASE_NOTES_0.4.0_RU.md).

Своих серверов у SvoRay нет — вы подключаетесь по собственной подписке.

## Зачем нужен SvoRay

SvoRay предназначен для людей, у которых уже есть совместимая с v2rayN подписка, но нет желания
каждый день разбираться в полном интерфейсе. Внутри остаются проверенные v2rayN, Xray и sing-box,
а основные действия собраны на одном понятном экране.

| Что нужно сделать | Простой экран SvoRay | Полный интерфейс v2rayN |
| --- | --- | --- |
| Подключиться на каждый день | Одна кнопка питания | Доступен в один клик |
| Выбрать сервер | Компактный список профилей | Полная таблица и группы |
| Настроить отдельные домены | Понятный список и набор для РФ | Полный редактор маршрутизации |
| Провести диагностику | Задержка и проверка адреса выхода | Все расширенные инструменты |

SvoRay не продаёт подписки и не привязывает пользователя к провайдеру. Можно вставить свою
подписку или отдельный профиль, а при необходимости открыть любую настройку исходного v2rayN.

## Что уже настроено

- запуск от имени администратора — необходим для TUN;
- русский и английский простой интерфейс; выбор RU/EN сохраняется и применяется после перезапуска;
- два режима подключения на выбор: TUN (весь трафик системы) и системный прокси Windows;
- маршрутизация по списку доменов: «всё через VPN, кроме списка» или «через VPN только список»;
- автоматический выбор активного Ethernet/Wi-Fi-адаптера и локального IPv4;
- автоматическое исключение IP выбранного VPN-сервера из TUN, чтобы избежать зацикливания;
- DNS Cloudflare: `1.1.1.1` и `https://1.1.1.1/dns-query`;
- TUN stack `gvisor`, MTU 1500, IPv6 в TUN выключен;
- импорт HTTPS-подписки или отдельных `vless://`, `hysteria2://` и других поддерживаемых v2rayN ссылок;
- кнопка поддержки: безопасная ссылка провайдера из подписки или GitHub Issues проекта;
- отдельный расширенный интерфейс для редких ручных настроек.

## Установка

1. Скачайте `SvoRay-0.4.0-setup.exe`.
2. Запустите установщик и подтвердите запрос Windows UAC.
3. Windows SmartScreen может показать предупреждение «Неизвестный издатель»: сборка не подписана коммерческим сертификатом. Чтобы продолжить, нажмите «Подробнее» → «Выполнить в любом случае».
4. По завершении можно сразу запустить приложение. Ярлык создаётся только в меню «Пуск».

Обновление: просто запустите установщик новой версии поверх текущей. Настройки, подписки и профили сохраняются.

Удаление: «Параметры» → «Приложения» → SvoRay → «Удалить». Деинсталлятор отдельно спросит, удалять ли настройки и подписки; по умолчанию они остаются.

## Использование

1. Запустите SvoRay и подтвердите запрос UAC.
2. При первом запуске используется язык интерфейса Windows. Чтобы сменить его, выберите RU или EN в шапке и перезапустите SvoRay по подсказке.
3. Экран предлагает добавить подключение: вставьте личную ссылку подписки или отдельный профиль и нажмите «Импортировать».
4. После успешного импорта форма заменяется селектором профиля; первый пригодный профиль выбирается автоматически.
5. Выберите режим: «Прокси» — через VPN идут программы, учитывающие системный прокси Windows; «TUN» — весь трафик системы.
6. Нажмите большую кнопку питания. Для выключения нажмите её ещё раз.
7. Кнопка «Обновить подписку» перечитывает список серверов. Если импортирован одиночный профиль без подписки, кнопка скрыта.
8. Кнопка «Проверить» при выключенном VPN измеряет задержку выбранного профиля, а при включённом — проверяет работающее соединение и показывает страну выхода и задержку. Замер идёт через сам прокси, а не простым TCP-соединением с сервером: TCP-соединение может успешно установиться и тогда, когда подключение на самом деле не работает.
9. Кнопка «Маршрутизация» открывает список доменов. Домен вводится как `example.com` — поддомены попадают в правило автоматически; список можно вставить целиком, а кнопка «Набор для РФ» заполняет его сайтами, которые обычно не работают с зарубежного адреса. DNS для таких доменов идёт тем же путём, что и трафик, иначе адрес вернулся бы «не из той страны».
10. Кнопка «Поддержка» открывает ссылку провайдера из подписки; если её нет или она небезопасна — GitHub Issues проекта.
11. Кнопка «Настройки» открывает полный интерфейс v2rayN для диагностики и редких ручных настроек.

Значок в трее показывает состояние формой, а не только цветом: пустой контур — выключен, контур с точкой — подключение, залитый щит — включён, щит с восклицательным знаком — ошибка. Левый клик открывает окно.

## Где хранятся данные

Начиная с 0.2.0 настройки, подписки, профили и логи хранятся в

```
%LOCALAPPDATA%\SvoRay
```

а не рядом с исполняемым файлом. При первом запуске 0.2.0 данные версии 0.1.x, лежавшие рядом с EXE, переносятся туда автоматически.

Эта папка содержит вашу ссылку подписки и учётные данные профилей. Не пересылайте её другим людям и не прикладывайте к отчётам об ошибках.

Примечание: приложение и установщик работают с правами администратора, поэтому `%LOCALAPPDATA%` — это профиль той учётной записи, под которой выполнено повышение прав. При обычном UAC-подтверждении того же пользователя это его собственный профиль.

## Ограничения

- сборка не подписана коммерческим сертификатом, поэтому Windows может показать SmartScreen «Неизвестный издатель»;
- автообновление самого v2rayN отключено, чтобы официальный релиз не перезаписал интерфейс SvoRay; обновление Xray/sing-box оставлено в расширенном режиме;
- одновременно включать TUN в официальном v2rayN и в SvoRay нельзя;
- приложение не обеспечивает анонимность и не гарантирует отсутствие утечек — оно лишь направляет трафик через выбранный вами сервер.

Поскольку подписи нет, единственный способ проверить загруженный файл — сверить его SHA256 с `SHA256SUMS.txt`, опубликованным рядом с релизом:

```powershell
Get-FileHash .\SvoRay-0.4.0-setup.exe -Algorithm SHA256
```

Что именно проверялось перед публикацией и какие риски остались — в `docs/SECURITY_AUDIT.md`.

## Сборка из исходного кода

Требуются .NET SDK 10 и Inno Setup 6 (`winget install --id JRSoftware.InnoSetup`).

```powershell
.\build\BuildInstaller.ps1
```

Скрипт публикует self-contained сборку, добавляет компоненты v2rayN/Xray/sing-box/geodata, собирает `SvoRay-0.4.0-setup.exe`, portable ZIP, source ZIP и `SHA256SUMS.txt` в каталог `dist`.

## Частые вопросы

### В SvoRay входят VPN-серверы?

Нет. Это клиент для вашей подписки или отдельного профиля. SvoRay не продаёт и не добавляет
доступ к сторонним серверам.

### Зачем приложению права администратора?

Они нужны режиму TUN для маршрутизации системного трафика. Также доступен режим системного прокси,
но сейчас приложение сразу запускается с повышенными правами, чтобы между режимами можно было
переключаться без перезапуска.

### Установщик подписан?

Коммерческого сертификата подписи пока нет, поэтому Windows SmartScreen может показать
«Неизвестный издатель». Перед запуском сравните хэш установщика с `SHA256SUMS.txt` из того же
релиза.

### Полные настройки v2rayN остались доступны?

Да. Кнопка настроек открывает исходный расширенный интерфейс для диагностики и ручной настройки.
